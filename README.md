# Social Media Transparency

Educational demo showing selected SMM source-list rates and a fully disclosed illustrative calculation.

Formula: provider cost + 35% handling markup + ₱50 per 1,000 units admin fee.

This project does not automatically place SMM orders. Artificial engagement is not organic growth and may be removed or penalized by platforms. No guarantee is made for real humans, retention, refill, refund, monetization, ranking, account safety or platform acceptance.

Run locally with: npm start
